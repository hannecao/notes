# novel-kit：长篇小说写作流程

GLM 写正文初稿，Claude / Codex 负责编排、审稿和更新状态。

这套流程针对旧做法的两个问题：

| 问题 | 原因 | 这里的做法 |
|---|---|---|
| token 越写越多 | 状态文件只加不减，每章都全读 | 每章只读固定清单，每个文件有字数上限；近况**整体重写**，旧内容进归档，平时不读 |
| 后面变流水账 | 细纲变粗、喂给模型的全是概括、文风逐章漂移 | 细纲写到**场景级**；每章附同一份**样章**；审稿查“好不好看”，不合格退回重写而不是删减 |

## 一本书的目录

```
<书名>/
├── 样章.md                 # 文风基准，固定不变
├── 00_设定/
│   ├── 固定设定.md         # ≤3000 字
│   └── 人物/<名字>.md      # 每人 ≤500 字
├── 01_规划/
│   ├── 卷1_节奏表.md
│   └── 细纲/ch001.md       # 每章 ≤1500 字，场景级
├── 02_状态/
│   ├── 近况.md             # ≤1500 字，每章整体重写
│   └── 伏笔账本.md         # 只放未收回的，≤15 条
├── 03_正文/ch001.md
├── 04_归档/                # 平时不读
│   ├── 近况历史.md
│   └── 已收伏笔.md
└── work/                   # prompt 和 GLM 原稿，可随时清理
```

每章读取总量约 1 万字，第 1 章和第 200 章一样多。

## 开始一本新书

1. `cp -r novel-kit/templates <书名>`
2. 填 `00_设定/固定设定.md`、主要人物卡、`01_规划/卷1_节奏表.md`。
3. 前 1–3 章写好后，挑最满意的一段放进 `样章.md`。在那之前，可以先放一段你喜欢的同类作品文字作为临时样章。
4. 之后每章按 [SKILL.md](SKILL.md) 走。

## 文件

- [SKILL.md](SKILL.md)：单章流程（给 Claude / Codex 读）
- [GLM-prompt模板.md](GLM-prompt模板.md)：发给 GLM 的 prompt
- [审稿表.md](审稿表.md)：审稿标准
- [templates/](templates/)：一本书的空白模板
- `scripts/check.py`：检查文件是否超字数上限，并算出最近几章的流水账指标

```
python novel-kit/scripts/check.py <书名> [最近章数，默认 5]
```
